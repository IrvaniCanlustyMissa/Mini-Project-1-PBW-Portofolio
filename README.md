# Project Portofolio Website

Tugas pembuatan website portofolio menggunakan HTML, CSS, Bootstrap 5, dan Vue JS.

## 1. Fitur & Tampilan
- **Home**: Hero section dengan perkenalan singkat dan foto profil.
- **About Me**: Deskripsi diri, daftar skill dengan progress bar, dan informasi latar belakang.
- **Certificates**: Daftar pencapaian dalam bentuk card layout yang rapi.
- **Responsive Design**: Tampilan dapat menyesuaikan ukuran layar (HP/Laptop).

## 2. Tools yang Digunakan
- **HTML**
- **CSS**
- **Bootstrap**
- **Vue JS 3**
